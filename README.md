# Yuqi Zhao's academic homepage

Source for [rigcor7.github.io](https://rigcor7.github.io), built with Jekyll and
GitHub Pages.

## Local development

```bash
bundle install
bundle exec jekyll serve --config _config.yml,_config.dev.yml
```

Main content lives in `_pages/` and `_teaching/`. Static documents are stored in
`files/`, and the profile image is `images/profile.png`.

The site is based on [Academic Pages](https://github.com/academicpages/academicpages.github.io).
